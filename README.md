# 🌴 HH Goa 2026 — Builder Access Pass Generator

> Generate your official, custom-styled **Builder Access Pass** for HH Goa 2026. Custom photo positioning, random hacker titles, responsive live preview, and instant HD PNG exports named after you.

---

## 🌟 Key Features

- **📷 Photo Upload & Live Adjustments**:
  - Upload your hacker avatar or photo.
  - Adjust **Zoom** (100% to 250%) and **Position (X & Y Pan)** in real time.
  - Single-click **Change photo** button to try different pictures.
- **🏷️ Customizable Builder Details**:
  - Enter your **Name**, **Stack/Role**, and **Team Name**.
  - Auto-generated **Pass ID** based on your builder profile.
- **⚡ Hacker Title Generator**:
  - One-click title generator to pick titles like `⚡ Coconut-Powered Coder ⚡` or `⚡ Midnight Deploy Wizard ⚡`.
- **🖼️ High-Res PNG Export**:
  - Exports HD 1080x1350 ticket passes instantly using HTML5 Canvas.
  - Automatically saves with a custom filename formatted to your name (`Your_Name_HH_Goa_2026_Pass.png`).
- **📱 Mobile-First Responsive Design**:
  - Fluid scaling (`clamp`), touch-optimized form inputs, and 0-overflow screen adaptation for mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack

- **Core**: React 19, TypeScript
- **Framework**: TanStack Start & TanStack Router
- **Styling**: Tailwind CSS v4, Custom CSS Design System
- **Icons**: Lucide React
- **Export Engine**: `html-to-image`

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm 9+

### Local Setup

1. **Clone the repository**:

   ```bash
   git clone https://github.com/NannawarePranav/hhg-team-FineTuned.git
   cd hhg-team-FineTuned
   ```

2. **Install dependencies**:

   ```bash
   npm install
   ```

3. **Start development server**:

   ```bash
   npm run dev
   ```

4. Open `http://localhost:8081` in your browser.
